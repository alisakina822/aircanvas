 AirCanvas--

Draw in the air using just your hand and webcam!

## Install-
pip install opencv-python mediapipe==0.10.9 numpy

## Run-
py -3.11 hand_draw.py

## Gestures-
| Gesture | Action |
|---|---|
| ☝️ 1 finger | Draw |
| ✌️ 2 fingers | Select colour |
| 4 fingers | Erase all |
| Fist ✊ | Drag drawing |
| Open palm 🖐️ | Release drag |
| C key | Clear canvas |
| ESC | Quit |
